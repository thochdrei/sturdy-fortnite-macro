PUT YOUR SCREENSHOTS IN THIS FOLDER
===================================
The macro finds buttons by looking for these pictures on your screen.
Use exactly these file names (all .png):

  ready.png     The READY / PLAY button in the lobby.
  nvidia.png    The NVIDIA Highlights button that appears when you are eliminated.
  menu.png      The menu button (take this screenshot AFTER pressing Esc in a match).
  leave.png     The Leave Match / Return to Lobby button.
  failsafe.png  Any extra button/popup you want clicked automatically while in a match.
                (After it is clicked, the macro waits 5 seconds and looks for ready.png.)

How to take them:
  1. Open the screen you want (Windows key + Shift + S opens the Snipping Tool).
  2. Crop TIGHTLY around the button or text, about 100-200 pixels wide.
  3. Don't include anything that changes (names, numbers, game scenery).
  4. Save as PNG with the exact name above, in this folder.
  5. Take them at the same resolution and UI scale you play at.
